## Install

1. Download **FileWizard-Setup.exe** below and run it (Windows 10/11, 64-bit).
2. Windows may show *"Windows protected your PC"*: the installer isn't code-signed yet. Click **More info → Run anyway**.
3. Right-click any file (or several) and choose **FileWizard**. On Windows 11 it's under *Show more options* unless you turn on the full menu in FileWizard's settings.

Uninstall any time from *Settings → Apps → FileWizard*; it leaves nothing behind.

Every release is built and tested by CI on real Windows (Explorer menu, installer, non-admin use, uninstall) before it is published. Source is MIT-licensed; bundled components are listed in THIRD_PARTY.md.
